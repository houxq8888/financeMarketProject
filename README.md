# financeMarketProject
金融市场微观结构分析

## 项目说明
本项目用于进行金融市场微观结构的实证分析，包括数据清洗、基准回归、中介效应检验和异质性分析等。

## 版本说明

### 1. 金融市场微观结构.py（原始版本）
- 需要原始数据文件：`A股创业板主板数据_2021-2025.dta`
- 包含完整的分析流程

### 2. 模拟数据生成.py
- 生成模拟数据文件：`A股创业板主板数据_2021-2025.dta`
- 用于在没有真实数据的情况下测试代码

### 3. 金融市场微观结构简化版.py
- 整合数据生成、清洗和分析
- 无需外部数据文件
- 适合快速测试代码逻辑

### 4. 金融市场微观结构真实数据版.py（优化版）
- 爬取真实的A股数据
- 包含完整的分析流程
- 需要安装akshare库

## 环境配置

### Anaconda环境设置
用户指定的Anaconda环境路径：`D:\ProgramData\miniconda3\envs\digitalP`

1. **激活环境**：
   ```bash
   conda activate digitalP
   ```

2. **安装依赖**：
   ```bash
   pip install pandas numpy statsmodels scipy akshare
   ```

## 运行步骤

### 选项1：使用真实数据爬取（推荐）

1. **安装依赖**：
   ```bash
   conda activate digitalP
   pip install akshare
   ```

2. **运行真实数据版本**：
   ```bash
   python 金融市场微观结构真实数据版.py
   ```

### 选项2：使用模拟数据

1. **生成模拟数据**：
   ```bash
   python 模拟数据生成.py
   ```

2. **运行原始版本**：
   ```bash
   python 金融市场微观结构.py
   ```

### 选项3：使用简化版

```bash
python 金融市场微观结构简化版.py
```

## 输出结果

- 基准回归结果
- 中介效应检验结果
- 异质性分析结果
