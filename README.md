# 金融市场微观结构作业 - DID分析

## 项目简介
该项目是基于Python的金融市场微观结构实证分析项目，使用双重差分法（DID）研究A股市场流动性与市场质量的关系。

## 主要功能
1. 数据爬取：使用akshare库爬取真实A股日线数据
2. 数据处理：计算流动性指标ILLIQ和换手率TURN，生成DID核心变量
3. 数据清洗：剔除ST股票、上市不足1年企业、金融行业，1%分位缩尾处理
4. 基准回归：双向固定效应DID模型，分析流动性变化
5. 结果输出：回归结果保存到Excel文件

## 文件说明
- `金融市场微观结构真实数据版.py`：主程序文件，包含完整的数据处理和回归分析流程
- `金融市场微观结构.py`：原参考文件（已由用户提供）
- `真实A股数据.xlsx`：爬取的原始数据保存文件（运行后生成）
- `真实数据回归结果.xlsx`：回归结果保存文件（运行后生成）

## 运行要求
1. 安装Python 3.x环境，并配置环境变量
2. 安装必要的依赖库：
   ```bash
   pip install pandas numpy statsmodels akshare openpyxl
   ```

## 运行步骤
1. 确保已安装所有依赖库
2. 运行主程序：
   ```bash
   python 金融市场微观结构真实数据版.py
   ```

## 注意事项
- 首次运行可能需要较长时间爬取数据
- 可根据需要修改股票列表和时间范围
- 若无法安装akshare，可使用模拟数据版本（需自行创建）
